# Changelog

All notable changes to `seal-key-server` are documented here.
Format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versioning follows [Semantic Versioning](https://semver.org/).
The version is the one in `VERSION`; a `v*` tag equal to it triggers the release. Before 0.2.0, breaking changes ship as patch releases.
Reconstructed from the git history on 2026-11-26 (this file did not exist before).

## [Unreleased]

## [0.0.5] - 2026-11-27

### Changed

- Documentation: every file is annotated line by line; added `CHANGELOG.md`, `CONTRIBUTING.md`, `CLAUDE.md` and `AGENTS.md`. No change to the image.

## [0.0.4] - 2026-11-06

### Security

- Runtime base is `gcr.io/distroless/cc-debian13:nonroot` (the debian12 base carried a fixable HIGH in `libssl3` that kept the weekly rescan red; audit F17).

## [0.0.3] - 2026-10-22

### Changed

- The binaries are built with `cargo auditable`, so Trivy and the SBOM list the compiled crates; CI fails if fewer than 100 are listed.
- Releases carry exact version tags only (no `latest`, no `0.0`); the image `version` label has no leading `v`; the weekly rescan scans the newest exact version tag.

## [0.0.2] - 2026-10-08

### Added

- A CI gate (hadolint, actionlint, Trivy configuration scan, an amd64 build, an image scan and a smoke test), the third-party licence notices generated by `cargo about`, credential-less builds, an upstream-release watch and `SECURITY.md`.

## [0.0.1] - 2026-10-02

### Added

- The contingency image of MystenLabs/seal `seal-v0.6.15` (pinned by tag and commit) and the tag-triggered publish workflow.
